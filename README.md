# 🧠 Product Analytics Playbook

> **A collection of structured case studies demonstrating North Star Metric design, metric-tree decomposition, and root-cause diagnostics for digital products.**

---

## 📌 About This Repository

This repository showcases my **product thinking and analytical approach** through real-world-inspired case studies. Each case study is built from first principles and demonstrates:

- ✅ North Star Metric selection for two-sided & three-sided marketplaces
- ✅ Metric tree decomposition (from high-level revenue down to conversion funnel)
- ✅ Guardrail design to prevent short-term optimization
- ✅ Root-cause diagnostics using segmentation & funnel analysis
- ✅ Hypothesis validation through A/B testing and historical comparison
